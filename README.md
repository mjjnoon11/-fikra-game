# فِكرة — لعبة تحدّي المعرفة

تطبيق عربي RTL للعب أسئلة مباشرة بين عدة أجهزة، مع مشاركة دعوة عبر WhatsApp. يحتوي على ٨ مجالات و٢٠٠ سؤال (منها أسئلة مصورة)، وتضم كل جلسة ٥ مراحل؛ في كل مرحلة ٥ أسئلة، مع توقف قصير متزامن بين المراحل.

## ما الجديد في هذه النسخة

- **إصلاح عطل جوهري**: المؤقّت (⏱) كان لا يعمل إطلاقاً — الدالة المسؤولة عنه كانت مفقودة من الكود، فيتجمّد العدّ التنازلي لكل الأسئلة. تم إضافتها وأصبح العدّ التنازلي يعمل بسلاسة مع تنبيه بصري عند اقتراب الوقت.
- **جاهزة للمشاركة باحتراف**: بطاقة معاينة (Open Graph) مصمَّمة بهوية اللعبة تظهر تلقائياً عند لصق الرابط في واتساب أو أي تطبيق آخر، وأيقونة ومجلد `assets/` مخصّصان، وتدعم "إضافة إلى الشاشة الرئيسية" (PWA) عبر `manifest.webmanifest`.
- **رمز QR في غرفة الدعوة**: لمن يلعبون في نفس المكان — مسح الرمز بالكاميرا يفتح رابط الانضمام مباشرة، دون الحاجة لإرساله.
- **روابط المعاينة تعمل تلقائياً على أي نطاق**: الخادم يبني رابط الصورة والعنوان بحسب النطاق الفعلي عند النشر (Render أو غيره)، فلا حاجة لتعديل يدوي بعد النشر.
- **أرقام عربية متّسقة**: كل الأرقام داخل اللعبة (المؤقّت، النقاط، عدد اللاعبين) تُعرض بالأرقام العربية بدل الغربية.
- لمسات صقل إضافية في الخادم (ضبط أنواع الملفات، تخزين مؤقت للأصول الثابتة، حماية أقوى من الوصول خارج مجلد المشروع).
- **زر خروج أثناء اللعب**: يمكن لأي لاعب مغادرة الجولة في أي لحظة من داخل شاشة السؤال أو فاصل المرحلة، دون انتظار نهاية التحدّي.
- **٤٠ سؤالاً جديداً بالإضافة إلى صور**: صار كل مجال يضم ٢٥ سؤالاً (٢٠٠ إجمالاً)، منها أسئلة مصوّرة (أعلام، معالم، حيوانات، أشكال هندسية...) لتنويع تجربة اللعب.
- **انضمام فوري من الرابط**: فتح رابط الدعوة يُدخل الضيف إلى الغرفة مباشرة دون شاشة إدخال كود.

## التشغيل محلياً

يتطلب Node.js 18 أو أحدث؛ لا توجد حزم خارجية.

```bash
npm start
# أو مباشرة:
node server.js
```

افتح `http://localhost:8000` للاختبار المحلي. للاستخدام من أجهزة أخرى، لا تشارك `localhost`؛ انشر التطبيق على عنوان HTTPS عام.

## النشر

يتضمن المشروع `Dockerfile` جاهزاً لمنصة تستضيف حاويات Docker. اربط مجلد المشروع بمستودع Git، أنشئ خدمة Web Service من مستودعك، واختر Dockerfile. يستمع الخادم إلى المنفذ الذي توفره المنصة عبر متغير البيئة `PORT`.

## آلية اللعب والمشاركة

1. المضيف ينشئ غرفة؛ الخادم يرجع رمزاً فريداً ورابطاً عاماً بالشكل `https://عنوان-الموقع/?join=CODE`.
2. المضيف ينسخ الرابط أو يضغط مشاركة واتساب؛ تفتح رسالة جاهزة تحتوي الرابط والرمز. عند إدخال رقم مباشر، يفتح WhatsApp المحادثة مع الرقم ورسالة الدعوة. يضغط المضيف إرسال بنفسه.
3. المدعو يفتح الرابط على جهازه، يكتب اسمه، ويضغط انضمام. ينضم إلى الغرفة نفسها؛ يُظهر المضيف قائمة اللاعبين مباشرة ويمكنه بدء الجولة.
4. الأسئلة والإجابات والنتائج تتزامن عبر الخادم؛ نمط الفرق يوزع اللاعبين تلقائياً بين فريقين.

لا يحتاج الإرسال إلى WhatsApp Business API. الرسالة تُجهّز في WhatsApp ولا تُرسل دون تأكيد المستخدم. دعوة الرقم تقبل رقم السعودية المحلي `05xxxxxxxx` أو الرقم الدولي.

## ملاحظات مهمة

- الغرف متعددة اللاعبين تعمل عبر API الخادم والاستطلاع الدوري، وتُحفظ في ذاكرة عملية الخادم؛ لذلك حذف الغرف يحدث عند إعادة تشغيل الخدمة، وتبقى الغرف مؤقتة حتى 6 ساعات.
- استخدم نسخة خادم واحدة لهذه النسخة. تشغيل عدة نسخ يتطلب تخزيناً مشتركاً مثل Redis/PostgreSQL وتنسيقاً بين النسخ.
- لا يمكن للطرف الآخر فتح رابط المعاينة المحلي/المؤقت؛ يلزم نشر التطبيق على HTTPS عام ثابت قبل مشاركة الرابط خارج بيئة التطوير.
- روابط واتساب تفتح رسالة جاهزة فقط؛ لا تُرسل الرسالة آلياً من دون موافقة المستخدم.
